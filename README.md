## Opis projektu (PL)
Interaktywne narzędzie dydaktyczne oraz uproszczony, geometryczny zegar astronomiczny obrazujący pełny cykl precesji osi Ziemi (**Rok Platoński – 25 920 lat**) bez użycia przekładni zębatych.

* **Zasada działania:** Przesunięcie pierścienia zodiakalnego o **1° odpowiada 72 latom** w rzeczywistości.
* **Konstrukcja:** Krzyż kardynalny wyznaczający punkty równonocy i przesileń (rozmieszczone co 180°) z centralnym gnomonem oraz zewnętrznym pierścieniem gwiazd okołobiegunowych (Polaris, Thuban, Vega).
* **Skalowalność:** Koncepcja może być zrealizowana zarówno jako prosty model papierowy, narzędzie edukacyjne w przeglądarce (HTML5), jak i kamienny zegar monumentalny.

## Project Description (EN)
A simplified, purely geometric astronomical clock and interactive educational simulator designed to track the 25,920-year cycle of axial precession (**the Platonic Year**) using a cardinal cross and manual 72-year calibration (**1° = 72 years**) without mechanical gears.
